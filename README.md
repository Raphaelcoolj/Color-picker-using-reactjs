# 🎨 Color Picker App

A sleek, intuitive, and interactive color picker built with **React** and **Vite**. This application allows users to select colors visually and instantly see their corresponding hex codes in a beautifully designed interface.

## ✨ Features

- **Real-time Preview**: See your selected color change instantly on the screen.
- **Hex Code Display**: Get the exact hex code of the color you've picked.
- **User-Friendly Interface**: Minimalist design with a focus on ease of use.
- **Modern Tech Stack**: Built with React 19 and Vite for lightning-fast performance.

## 🚀 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Raphaelcoolj/Color-picker-using-reactjs.git

   cd color-picker-app/my-app
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

The app will be available at `http://localhost:5173`.

## 🛠️ Technologies Used

- **React 19**: A JavaScript library for building user interfaces.
- **Vite**: Next-generation frontend tooling for fast development.
- **CSS3**: Custom styling for a premium look and feel.
